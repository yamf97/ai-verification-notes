# 사례 09 — 교재 없는 강의: 판서와 자막이 서로를 검사한다

## 무슨 일이 있었나

계량경제학 강의(Ben Lambert의 대학원 계량경제학 YouTube 강의 74강)를 공부하려는데 **교재가 없었습니다.** 강의에 있는 것은 말과 판서뿐입니다. 그래서 두 가지를 텍스트로 만들어 노트를 쓰기로 했습니다.

| 출처 | 어떻게 텍스트로 | 누가 |
|---|---|---|
| 말 | YouTube 자막 74강을 받는 스크립트 | 직접 만듦 |
| 판서 | 지인이 AI로 영상에서 캡처해 준 판서 PDF(쪽당 1강, 이미지만 있음)를 LaTeX로 옮김 | AI가 쪽 이미지를 보고 옮김. OCR 프로그램은 쓰지 않음 |

## 자막 받기에서 막힌 것

| 문제 | 해결 |
|---|---|
| 요청이 많아 집 회선이 차단됨 | 강의 사이 20~40초 무작위 대기, 10강마다 3분 쉼, **첫 차단 응답에서 즉시 중단** |
| 실패해도 정상 종료로 끝나 오류 문구가 자막 파일로 저장됨 | 오류 문구 검사 추가, 잘못 저장된 파일 삭제 |
| 08·09번을 8진수로 읽음, `-`로 시작하는 영상 ID를 옵션으로 읽음 | 번호와 인자 처리 수정 |

결과: 74/74, 실패 0. 첫 줄 제목, URL, 오류 문구 0건까지 전부 확인했습니다.

## 판서를 옮기는 규칙

- 판서의 위→아래, 왼→오른쪽 순서를 지킵니다.
- 색, 화살표, 밑줄 같은 것은 식에 넣지 않고 `[판서 주석]`으로 따로 적습니다.
- 판서의 표기 약속(밑줄 = 벡터 등)은 **자막에서 근거를 찾아** 적습니다.
- 손글씨를 확실히 못 읽은 곳은 `[원문 미확인 — 판독]`으로 표시하고, 파일 끝 「판독 불확실 모음」 표에 모아 한 번에 회수합니다.

강의 하나는 이런 꼴입니다.

```
## L01 <강의 제목>
### 판서         ← 판서 순서대로 LaTeX
### 자막과 대조   ← | 항목 | 판서 | 자막 | 판정 |
```

## 판서와 자막을 대조했더니

**판서를 옮긴 진짜 이유가 여기 있었습니다.** 두 자료는 서로 다른 경로로 만들어졌기 때문에 서로의 오류를 잡습니다.

| 잡은 것 | 예 |
|---|---|
| 자막의 음성 인식 오류 | 판서에는 $N$인데 자막은 "M by one" |
| **강사의 말실수** (4건) | 판서와 다른 단어를 말함("diagonal", "column", "not singular"), 강의 도중 스스로 정정 |
| 판서와 자막이 **함께** 틀린 곳 | 계수 벡터의 원소는 $\beta_0 \dots \beta_p$로 $p+1$개인데, 판서와 자막 모두 "p×1" |
| 판서의 판독 불확실 | 판서는 $X_{1N}$으로 보이나 자막상 $X_{2N}$ |
| 노트에 쓸 사실 | 어떤 강의의 판서에는 조건부 단계 없이 결과만 남아 있음 → 노트에 반영 |

자막 인용은 자동 자막 그대로(오인식 포함) 두고, 전부 원래 자막 파일과 문자열로 대조했습니다.

## 점검 도구도 검증 대상이다

노트를 점검하는 도구(인용이 자막에 글자 그대로 있는지, 시각이 맞는지 확인)를 만들어 쓰면서 "문제 없음"을 여러 번 보고했습니다. 그런데 다른 회사 모델에게 이 작업을 교차검토시키자, 가장 심각한 지적 3건이 **전부 점검 도구 자체의 결함**이었습니다.

→ **점검 도구가 "문제 없음"이라고 하면, 그 도구가 맞는지도 확인합니다.**

## 아직 하지 않은 것

- 영상에서 판서 프레임을 **직접** 뽑지는 않았습니다. 캡처는 받은 것이었습니다.
- 판서를 옮긴 것은 74강 중 16강입니다.

다음 단계로 생각하는 흐름(아직 해 보지 않음):
1. 영상을 받아 장면이 바뀌는 순간(판서 지우기, 슬라이드 넘김)이나 일정 간격으로 프레임을 뽑습니다.
2. 거의 같은 장면은 걸러 냅니다.
3. 위 규칙대로 옮기고 자막과 대조합니다.
4. 그러면 지금은 없는 **판서의 시각**이 생겨 자막 시각과 바로 이어집니다.

미리 보이는 위험: 한 화면에 계속 써 나가는 강의는 장면 변화로만 뽑으면 지우기 직전 한 장만 남습니다. 칠판을 비추지 않는 장면도 골라내야 합니다.

## 이 사례의 한계

강의 한 묶음, 16강에서 얻은 결과입니다. 강사의 말실수 판단은 판서·자막·수학적 일관성으로 한 것이고, `[외부 추론]`으로 표시해 두었습니다.
